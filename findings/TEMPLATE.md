# <what was actually wrong>

**Found:** <when, and by what> · **Fixed in:** <commit or release>

## Symptom

What was observed, in the order it was observed. Include the numbers
that looked wrong — an impossible value is usually the first real
signal.

## Cause

One cause, stated once. If there appear to be several, look again: four
symptoms from one defect is common, and presenting them as four bugs
suggests four fixes.

## Why it was not caught earlier

The most valuable section. A test that pinned the broken behaviour, an
environment where the defect could not appear, a diagnostic that was
silenced by a default — these are the things that will hide the next
one too.

## Wrong hypotheses along the way

Each one, and what disproved it. This is not self-flagellation: a reader
who holds the same wrong theory is saved the detour, and a pattern of
mistakes is itself a finding.

## What would have found it faster

The measurement, probe or guard that settled it. If a guard now exists,
link it and say what it would have caught.
